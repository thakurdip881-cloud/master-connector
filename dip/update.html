🚀 अपडेट पैनल

यहाँ सोर्स कोड डालें → GitHub में जाएगा → Netlify अपने-आप ऐप अपडेट करेगा → सबके APK में नया वर्ज़न।

🔑 1. एक बार की सेटिंग

Token कैसे बनाएँ?
  1. यह खोलें: github.com/settings/personal-access-tokens/new
  2. Token name: update-panel · Expiration: 1 साल
  3. Repository access: Only select repositories → Dip
  4. Permissions → Repository → Contents: Read and write
  5. Generate token → कॉपी करके ऊपर डालें

📤 2. नया कोड डालें

↩ 3. गलती हो गई? पिछला वर्ज़न वापस लाएँ

✅ ऐप अपने-आप तभी अपडेट होगा जब Netlify की साइट इसी GitHub repo से जुड़ी हो।
⏱ GitHub में जाने के बाद Netlify को ऐप अपडेट करने में आम तौर पर 1–2 मिनट लगते हैं। APK खोलकर नीचे खींचें (refresh) या दोबारा खोलें।
💡 हर अपडेट पर Netlify थोड़े credits लेता है — कई बदलाव हों तो एक साथ चढ़ाएँ।
